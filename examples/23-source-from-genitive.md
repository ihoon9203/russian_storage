# 출발점: `из + 생격` / Source with `из`

`откуда?`에 답하며, 장소의 내부에서 밖으로 나오거나 그곳에서 출발하는 상황을 말한다.

| 러시아어 예문 | 한국어 뜻 | 관련 어휘 | 문법 포인트 |
|---|---|---|---|
| `Я выхожу из комнаты.` | 나는 방에서 나온다. | [일과와 시간](../vocabulary/23-daily-routine-and-time.md), [집](../vocabulary/home.md) | [생격: `из комнаты`](../cases/genitive.md), [현재형](../grammar/09-present-tense.md) |
| `Мой друг выходит из офиса.` | 내 친구는 사무실에서 나온다. | [가족·관계](../vocabulary/family-and-relationships.md), [직업·직장](../vocabulary/work-and-professions.md), [일과와 시간](../vocabulary/23-daily-routine-and-time.md) | [생격: `из офиса`](../cases/genitive.md), [소유대명사](../grammar/22-possessives.md) |
| `Мы выходим из парка.` | 우리는 공원에서 나온다. | [일과와 시간](../vocabulary/23-daily-routine-and-time.md), [도시·장소](../vocabulary/city-and-places.md) | [생격: `из парка`](../cases/genitive.md), [현재형](../grammar/09-present-tense.md) |
| `Мама выходит из магазина.` | 엄마는 가게에서 나온다. | [가족·관계](../vocabulary/family-and-relationships.md), [쇼핑](../vocabulary/shopping.md), [일과와 시간](../vocabulary/23-daily-routine-and-time.md) | [생격: `из магазина`](../cases/genitive.md) |
| `Я выхожу из ресторана.` | 나는 식당에서 나온다. | [일과와 시간](../vocabulary/23-daily-routine-and-time.md), [식당·주문](../vocabulary/restaurant-and-ordering.md) | [생격: `из ресторана`](../cases/genitive.md) |
| `Мой брат выходит из музея.` | 내 형제는 박물관에서 나온다. | [가족·관계](../vocabulary/family-and-relationships.md), [예술·문화](../vocabulary/arts-and-culture.md), [일과와 시간](../vocabulary/23-daily-routine-and-time.md) | [생격: `из музея`](../cases/genitive.md), [소유대명사](../grammar/22-possessives.md) |
| `Мы едем из города.` | 우리는 도시에서 출발해 간다. | [교통·이동](../vocabulary/transport-and-movement.md), [도시·장소](../vocabulary/city-and-places.md) | [생격: `из города`](../cases/genitive.md), [현재형](../grammar/09-present-tense.md) |
| `Я достаю книгу из сумки.` | 나는 가방에서 책을 꺼낸다. | [일과와 시간](../vocabulary/23-daily-routine-and-time.md), [학교·공부](../vocabulary/school-and-study.md), [옷과 소지품](../vocabulary/24-clothing-and-belongings.md) | [생격: `из сумки`](../cases/genitive.md), [현재형](../grammar/09-present-tense.md) |
| `Моя сестра выходит из школы.` | 내 자매는 학교에서 나온다. | [가족·관계](../vocabulary/family-and-relationships.md), [학교·공부](../vocabulary/school-and-study.md), [일과와 시간](../vocabulary/23-daily-routine-and-time.md) | [생격: `из школы`](../cases/genitive.md), [소유대명사](../grammar/22-possessives.md) |
| `Я выхожу из коридора.` | 나는 복도에서 나온다. | [일과와 시간](../vocabulary/23-daily-routine-and-time.md), [집](../vocabulary/home.md) | [생격: `из коридора`](../cases/genitive.md) |

같은 장소를 위치·목적지·출발점으로 바꾸면 `в комнате → в комнату → из комнаты`가 된다.
