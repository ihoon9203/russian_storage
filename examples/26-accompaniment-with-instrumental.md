# 동행: `с + 조격` / Accompaniment with `с`

`с кем? / с чем?`에 답하며, 사람과 함께 행동하거나 음식·음료를 곁들이는 상황을 말한다.

| 러시아어 예문 | 한국어 뜻 | 관련 어휘 | 문법 포인트 |
|---|---|---|---|
| `Я гуляю с другом.` | 나는 친구와 산책한다. | [가족·관계](../vocabulary/family-and-relationships.md), [달리기와 야외](../vocabulary/22-running-and-outdoors.md) | [조격: `с другом`](../cases/instrumental.md) |
| `Мы ужинаем с мамой.` | 우리는 엄마와 저녁을 먹는다. | [가족·관계](../vocabulary/family-and-relationships.md), [일과와 시간](../vocabulary/23-daily-routine-and-time.md) | [조격: `с мамой`](../cases/instrumental.md), [현재형](../grammar/09-present-tense.md) |
| `Она идёт в парк с сестрой.` | 그녀는 자매와 공원으로 간다. | [가족·관계](../vocabulary/family-and-relationships.md), [도시·장소](../vocabulary/city-and-places.md) | [조격: `с сестрой`](../cases/instrumental.md), [대격: `в парк`](../cases/accusative.md) |
| `Я говорю с братом.` | 나는 형제와 이야기한다. | [가족·관계](../vocabulary/family-and-relationships.md), [의사소통](../vocabulary/communication.md) | [조격: `с братом`](../cases/instrumental.md) |
| `Мы бегаем с подругой.` | 우리는 여자 친구와 달린다. | [가족·관계](../vocabulary/family-and-relationships.md), [달리기와 야외](../vocabulary/22-running-and-outdoors.md) | [조격: `с подругой`](../cases/instrumental.md), [현재형](../grammar/09-present-tense.md) |
| `Мой друг гуляет с собакой.` | 내 친구는 개와 산책한다. | [가족·관계](../vocabulary/family-and-relationships.md), [동물](../vocabulary/animals.md), [달리기와 야외](../vocabulary/22-running-and-outdoors.md) | [조격: `с собакой`](../cases/instrumental.md), [소유대명사](../grammar/22-possessives.md) |
| `Я пью кофе с молоком.` | 나는 우유를 넣은 커피를 마신다. | [음료](../vocabulary/drinks.md) | [조격: `с молоком`](../cases/instrumental.md) |
| `Она живёт с семьёй.` | 그녀는 가족과 함께 산다. | [가족·관계](../vocabulary/family-and-relationships.md), [생활·존재](../vocabulary/living-and-existence.md) | [조격: `с семьёй`](../cases/instrumental.md) |
| `Мы идём в музей с папой.` | 우리는 아빠와 박물관에 간다. | [가족·관계](../vocabulary/family-and-relationships.md), [예술·문화](../vocabulary/arts-and-culture.md) | [조격: `с папой`](../cases/instrumental.md), [대격: `в музей`](../cases/accusative.md) |
| `Я работаю с другом.` | 나는 친구와 함께 일한다. | [가족·관계](../vocabulary/family-and-relationships.md), [직업·직장](../vocabulary/work-and-professions.md) | [조격: `с другом`](../cases/instrumental.md), [현재형](../grammar/09-present-tense.md) |

출발점을 뜻하는 `с работы`는 `с + 생격`이므로 동행의 `с другом`과 구분한다.
