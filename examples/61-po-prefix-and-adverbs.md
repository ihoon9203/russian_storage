# `по-`가 붙은 동사와 부사

| 러시아어 | 한국어 | 관련 어휘 | 문법 포인트 |
|---|---|---|---|
| `Я немного почитаю.` | 좀 읽을게. | [학교·공부](../vocabulary/school-and-study.md) | [얼마간 하는 동작](../grammar/25-prefixes-and-aspect.md), [완료상 미래](../grammar/11-aspect-and-future.md) |
| `Подожди немного.` | 조금 기다려. | [집 외부·건물 이동](../vocabulary/home-exterior-and-stairs.md) | [명령형](../grammar/24-imperatives-and-proposals.md) |
| `Поехали!` | 출발하자! | [교통·이동](../vocabulary/transport-and-movement.md) | [이동의 시작](../grammar/25-prefixes-and-aspect.md), [제안](../grammar/24-imperatives-and-proposals.md) |
| `Пойдём!` | 가자! | [교통·이동](../vocabulary/transport-and-movement.md) | [이동의 시작](../grammar/25-prefixes-and-aspect.md), [제안](../grammar/24-imperatives-and-proposals.md) |
| `Мы пообедали дома.` | 우리는 집에서 점심을 먹었다. | [일과와 시간](../vocabulary/23-daily-routine-and-time.md) | [한 번의 식사](../grammar/25-prefixes-and-aspect.md) |
| `Я тебе позвоню.` | 내가 너에게 전화할게. | [의사소통](../vocabulary/communication.md) | [완료상 미래](../grammar/11-aspect-and-future.md), [동사와 여격](../grammar/21-governed-cases.md) |
| `Давай сделаем по-другому.` | 다른 방식으로 해 보자. | [반응·대조 표현](../vocabulary/conversation-reactions-and-contrast.md) | [`по-` 부사](../grammar/25-prefixes-and-aspect.md), [제안](../grammar/24-imperatives-and-proposals.md) |
| `Теперь мы работаем по-новому.` | 이제 우리는 새로운 방식으로 일한다. | [반응·대조 표현](../vocabulary/conversation-reactions-and-contrast.md) | [`по-` 부사](../grammar/25-prefixes-and-aspect.md) |
| `По-моему, так лучше.` | 내 생각에는 이렇게 하는 게 더 좋아. | [반응·대조 표현](../vocabulary/conversation-reactions-and-contrast.md) | [`по-` 부사](../grammar/25-prefixes-and-aspect.md) |

`Поехали!`는 `поехать`의 복수 과거형을 출발 권유로 쓴 표현이다. `Пойдём!`은 완료상 `пойти`의 1인칭 복수 미래형을 권유로 쓴다.
