- 새 단어는 이미 아는 문장 구조에 넣어 말한다.
- 새 문장 구조는 이미 아는 단어로 연습한다.
- 뜻을 다시 읽는 것보다 회상, 간격 반복, 여러 문맥에서의 사용을 우선한다.
- 단어와 문법에는 실제 러시아어 예문을 함께 둔다.
- 예문에는 관련 어휘와 문법 문서를 연결한다.
- 오답은 어휘와 문법으로 나눠 원인과 판단 기준을 함께 기록한다.
