# 2. 격변화 테스트 기록

## 기록 방식

- 맞힌 항목과 틀린 항목을 모두 기록한다.
- 항목별 최근 10회 결과로 숙련도를 계산하고, 한 번 틀렸다고 0으로 초기화하지 않는다.
- 점수가 낮은 항목은 자주, 높은 항목은 가끔 다시 출제한다.
- 격을 고르는 능력과 실제 어미를 만드는 능력을 구분해서 본다.
- 목표는 모든 항목을 최근 10회 기준 `8~9/10` 이상으로 유지하는 것이다.

| `около + 생격` | `магазин` | `магазина` | `магазина` | 정답 | 1/1 |
| `для + 생격` | `мама` | `мамы` | `мамы` | 정답 | 1/1 |
