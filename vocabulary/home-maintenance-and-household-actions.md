# 집 관리·생활 동작

| 러시아어 | 구분 | 뜻 | 발음 | 예문 | 숙련도 |
|---|---|---|---|---|---|
| `бытовая техника` | F, 표현 | 가전제품 | bytovaya tekhnika / 븨따바야 쩨흐니까 | `Бытовая техника стоит дорого.` | 미평가 |
| `ремонт` | M | 수리, 보수, 리모델링 | remont / 리몬트 | `Мы делаем ремонт в квартире.` | 미평가 |
| `ремонтировать` | 불완료상 동사 | 수리하다, 보수하다 | remontirovat / 리만찌라바찌 | `Мы ремонтируем квартиру с другом.` | 미평가 |
| `разбивать / разбить` | 불완료상/완료상 동사 | 깨뜨리다, 부수다 | razbivat / razbit / 라즈비바찌 / 라즈비찌 | `Он разбил чашку.` | 미평가 |
| `выбрасывать / выбросить` | 불완료상/완료상 동사 | 버리다 | vybrasyvat / vybrosit / 븨브라스이바찌 / 븨브라시찌 | `Я выбрасываю ненужные вещи.` | 미평가 |
| `выносить / вынести` | 불완료상/완료상 동사 | 밖으로 가지고 나가다 | vynosit / vynesti / 븨나시찌 / 븨니스찌 | `Он вынес стул из комнаты.` | 미평가 |
| `использовать` | 동사 | 사용하다 | ispolzovat / 이스뽈자바찌 | `Мы используем эту технику.` | 미평가 |
| `ломаться / сломаться` | 불완료상/완료상 재귀동사 | 망가지다, 고장 나다 | lomatsya / slomatsya / 라마차 / 슬라마차 | `Телевизор сломался.` | 미평가 |
| `снимать / снять` | 불완료상/완료상 동사 | 벗기다, 내려놓다, 떼다 | snimat / snyat / 스니마찌 / 스냐찌 | `Мама снимает кастрюлю с плиты.` | 미평가 |
| `поднимать / поднять` | 불완료상/완료상 동사 | 들어 올리다, 집어 올리다 | podnimat / podnyat / 빠드니마찌 / 빠드냐찌 | `Я поднимаю футболку с пола.` | 미평가 |

`разбивать`은 동작의 진행·반복, `разбить`는 깨뜨려 결과가 생긴 한 번의 완료를 나타낸다. 같은 방식으로 `выбрасывать / выбросить`, `выносить / вынести`, `ломаться / сломаться`, `снимать / снять`, `поднимать / поднять`도 불완료상과 완료상을 구별한다.
