# 동사

| 원형 | 뜻 | 함께 기억할 형태·표현 | 숙련도 |
|---|---|---|---|
| `быть` | 있다, ~이다 | `есть`, `был/была/было/были`, `буду` | 미평가 |
| `жить` | 살다 | `живу`, `живём`, `живут` | 미평가 |
| `учиться` | 공부하다 | `учусь` | 미평가 |
| `говорить` | 말하다 | `говорю`, `говорят`, `по-русски` | 미평가 |
| `работать` | 일하다 | `работаю`, `работаем`, `работают` | 미평가 |
| `хотеть` | 원하다 | `хочу`, `хочешь`, `хочет`, `хотят` | 미평가 |
| `мочь` | 할 수 있다 | `могу + 동사원형` | 미평가 |
| `уметь` | 할 줄 알다 | `умею + 동사원형` | 미평가 |
| `любить` | 좋아하다, 사랑하다 | `люблю + 대격/동사원형` | 미평가 |
| `нравиться` | 마음에 들다 | `нравится`, `нравятся` | 미평가 |
| `читать` | 읽다 | `люблю читать` | 미평가 |
| `видеть` | 보다 | `вижу` | 미평가 |
| `знать` | 알다 | `знаю`, `знают` | 미평가 |
| `понимать` | 이해하다 | `понимаю`, `не понимаю` | 미평가 |
| `кушать` | 먹다 | `хочу кушать` | 미평가 |
| `танцевать` | 춤추다 | `нравится танцевать` | 미평가 |
| `покупать` | 사다 | 불완료상 | 미평가 |
| `купить` | 사다 | 완료상, `куплю` | 미평가 |
| `приехать` | 타고 오다, 도착하다 | `приехал`, `приехали` | 미평가 |
| `сказать` | 말하다 | 완료상, `сказал/сказала/сказали` | 미평가 |
| `выглядеть` | ~처럼 보이다 | `выглядит классно` | 미평가 |
| `давать` | 주다 | 명령형 `давай` | 미평가 |
| `дать` | 주다 | `дал`, `дали` | 미평가 |
| `идти` | 걸어서 가다 | `иду` | 미평가 |
| `убирать` | 치우다, 정리하다 | ubirat / 우비라찌; `Я убираю комнату.` | 미평가 |
| `открывать` | 열다 | otkryvat / 앗끄릐바찌; `Я открываю дверь.` | 미평가 |
| `закрывать` | 닫다 | zakryvat / 자끄릐바찌; `Я закрываю окно.` | 미평가 |
| `познакомиться` | 처음 만나 인사하다 | `Рад/Рада был/была познакомиться` | 미평가 |
