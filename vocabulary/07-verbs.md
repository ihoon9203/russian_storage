# 동사

| 원형 | 뜻 | 함께 기억할 형태·표현 |
|---|---|---|
| `быть` | 있다, ~이다 | `есть`, `был/была/было/были`, `буду` |
| `жить` | 살다 | `живу`, `живём`, `живут` |
| `учиться` | 공부하다 | `учусь` |
| `говорить` | 말하다 | `говорю`, `говорят`, `по-русски` |
| `работать` | 일하다 | `работаю`, `работаем`, `работают` |
| `хотеть` | 원하다 | `хочу`, `хочешь`, `хочет`, `хотят` |
| `мочь` | 할 수 있다 | `могу + 동사원형` |
| `уметь` | 할 줄 알다 | `умею + 동사원형` |
| `любить` | 좋아하다, 사랑하다 | `люблю + 대격/동사원형` |
| `нравиться` | 마음에 들다 | `нравится`, `нравятся` |
| `читать` | 읽다 | `люблю читать` |
| `видеть` | 보다 | `вижу` |
| `знать` | 알다 | `знаю`, `знают` |
| `понимать` | 이해하다 | `понимаю`, `не понимаю` |
| `кушать` | 먹다 | `хочу кушать` |
| `танцевать` | 춤추다 | `нравится танцевать` |
| `покупать` | 사다 | 불완료상 |
| `купить` | 사다 | 완료상, `куплю` |
| `приехать` | 타고 오다, 도착하다 | `приехал`, `приехали` |
| `сказать` | 말하다 | 완료상, `сказал/сказала/сказали` |
| `выглядеть` | ~처럼 보이다 | `выглядит классно` |
| `давать` | 주다 | 명령형 `давай` |
| `дать` | 주다 | `дал`, `дали` |
| `идти` | 걸어서 가다 | `иду` |
| `убирать` | 치우다, 정리하다 | 불완료상 |
| `открывать` | 열다 | 불완료상 |
| `закрывать` | 닫다 | 불완료상 |
| `познакомиться` | 처음 만나 인사하다 | `Рад/Рада был/была познакомиться` |
