# 형용사와 상태 표현

| 러시아어 | 뜻 | 비고 |
|---|---|---|
| `новый` | 새로운 | 여성 `новая`, 중성 `новое`, 복수 `новые` |
| `чистый` | 깨끗한 | 사전형 남성 |
| `грязный` | 더러운 | 사전형 남성 |
| `родной` | 모국의, 고향의, 친족인 | `родной язык` |
| `нужен` | 필요한 | `нужна/нужно/нужны` |
| `русский` | 러시아의, 러시아인 남성 | 문맥에 따라 러시아어 |
| `корейский` | 한국의, 한국어의 | `корейский язык` |
| `английский` | 영국의, 영어의 | `английский язык` |
