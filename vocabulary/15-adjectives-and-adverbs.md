# 형용사와 부사 확장

| 러시아어 | 뜻 | 변화·예문 |
|---|---|---|
| `большой` | 큰 | `большая/большое/большие`; `большой дом` |
| `маленький` | 작은 | `маленькая/маленькое/маленькие`; `маленькое окно` |
| `красивый` | 아름다운, 남성 문맥에서 잘생긴 | `Он очень красивый.` |
| `вкусный` | 맛있는 | `Как твоя пицца? Вкусная?` |
| `молодой` | 젊은 | `Он молодой.` |
| `приятный` | 기분 좋은 | `Приятного отдыха!` |
| `хороший` | 좋은 | `Он хороший специалист.` |
| `очень` | 매우, 아주 | `Это очень красивое место.` |
| `хорошо` | 잘, 좋아 | `Я хорошо говорю по-русски.` |
| `сейчас` | 지금 | `Она сейчас в Одессе.` |
| `вчера` | 어제 | `Я прилетел вчера.` |
| `сразу` | 곧바로 | `Он сразу позвонил.` |
| `давно` | 오래전에, 오랫동안 | `Давно не виделись!` |
| `сюда` | 여기로 | `Я приехал сюда.` |
| `завтра` | 내일 | `Я позвоню завтра.` |
| `всё` | 모든 것, 전부 | `Всё хорошо.` |
