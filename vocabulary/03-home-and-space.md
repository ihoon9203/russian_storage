# 집과 공간

| 러시아어 | 발음 | 구분 | 뜻 | 숙련도 |
|---|---|---|---|---|
| `дом` | dom / 돔 | M | 집 | 미평가 |
| `комната` | komnata / 꼼나따 | F | 방 | 미평가 |
| `кухня` | kukhnya / 꾸흐냐 | F | 부엌 | 미평가 |
| `туалет` | tualet / 뚜알렛 | M | 화장실 | 미평가 |
| `гостиная` | gostinaya / 가스찌나야 | F | 거실 | 미평가 |
| `спальня` | spalnya / 스빨냐 | F | 침실 | 미평가 |
| `ванная` | vannaya / 반나야 | F | 욕실 | 미평가 |
| `балкон` | balkon / 발콘 | M | 발코니, 베란다 | 미평가 |
| `коридор` | koridor / 까리도르 | M | 복도 | 미평가 |
| `угол` | ugol / 우골 | M | 구석, 모서리 | 미평가 |
| `дверь` | dver / 드베리 | F | 문 | 미평가 |
| `окно` | okno / 아크노 | N | 창문 | 미평가 |
| `стена` | stena / 스찌나 | F | 벽 | 미평가 |
| `пол` | pol / 뽈 | M | 바닥 | 미평가 |

| `адрес` | adres / 아드레스 | M | 주소 | 미평가 |
| `внутри` | vnutri / 브누뜨리 | 부사·전치사 | 안에, 내부에 | 미평가 |
| `снаружи` | snaruzhi / 스나루지 | 부사·전치사 | 밖에, 외부에 | 미평가 |
