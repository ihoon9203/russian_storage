# 가족과 인간관계 확장

| 러시아어 | 구분 | 뜻 | 예문 |
|---|---|---|---|
| `муж` | M | 남편 | `У моего мужа есть машина.` |
| `жена` | F | 아내, 부인 | `У жены есть машина.` |
| `супруг / супруга` | M/F | 배우자, 격식체 남편/아내 | `Это мой супруг.` |
| `супруги` | Pl. | 부부 | `Они супруги.` |
| `сын` | M | 아들 | `У матери есть сын.` |
| `сестра` | F | 자매 | `Моя сестра живёт здесь.` |
| `брат` | M | 형제 | `Я говорю о своём брате.` |
| `внук / внучка` | M/F | 손자/손녀 | `У нас есть внуки.` |
| `родственник / родственница` | M/F | 남성/여성 친척 | `У меня много родственников.` |
| `родственники` | Pl. | 친척들 | `Мои родственники живут в Корее.` |
| `подруга` | F | 여성인 친구 | `Она моя подруга.` |
| `сосед / соседка` | M/F | 이웃 | `Это моя соседка.` |
| `сосед / соседка по комнате` | 표현 | 남자/여자 룸메이트 | `Я ваша соседка по комнате.` |
| `коллега по работе` | 표현 | 직장 동료 | `Он мой коллега по работе.` |
| `товарищ по команде` | 표현 | 팀 동료 | `Он мой товарищ по команде.` |
