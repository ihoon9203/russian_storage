# 추가 동사

| 원형 | 뜻 | 예문 |
|---|---|---|
| `думать` | 생각하다 | `Что ты думаешь?` |
| `смотреть` | 보다, 시청하다 | `Я смотрю фильм.` |
| `слушать` | 듣다 | `Я слушаю музыку.` |
| `писать` | 쓰다 | `Я пишу письмо.` |
| `есть` | 먹다 | `Я хочу есть.` |
| `пить` | 마시다 | `Я хочу пить.` |
| `заботиться` | 돌보다 | `Она заботится о семье.` |
| `позаботиться` | 챙기다, 돌봄을 완수하다 | `Я позабочусь об этом.` |
| `позвонить` | 전화하다 | `Я позвоню тебе.` |
| `скучать` | 그리워하다 | `Я скучаю по тебе.` |
| `надеяться` | 바라다, 기대하다 | `Я надеюсь на помощь.` |
| `показать` | 보여주다 | `Покажите мне паспорт.` |
| `помочь` | 돕다 | `Я помогу вам.` |
| `прилететь` | 비행기로 도착하다 | `Я прилетел вчера.` |
| `изучать` | 공부하다, 연구하다 | `Я изучаю русский язык.` |
| `преподавать` | 가르치다 | `Она преподаёт русский язык.` |
| `звать` | 부르다 | `Меня зовут Анна.` |
| `увидеть` | 보게 되다, 만나다 | `Я хочу увидеть Москву.` |

`есть`는 문맥에 따라 “있다” 또는 “먹다”이며, 뜻과 문장 구조로 구별한다.
