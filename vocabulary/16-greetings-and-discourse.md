# 인사와 담화 표현

| 표현 | 뜻 | 예문·메모 | 숙련도 |
|---|---|---|---|
| `Здравствуйте!` | 안녕하세요 | 격식체 | 미평가 |
| `Здравствуй!` | 안녕 | 한 사람에게 친근하게 | 미평가 |
| `Привет!` | 안녕 | 일상적 | 미평가 |
| `Доброе утро!` | 좋은 아침입니다 | 아침 인사 | 미평가 |
| `Добрый день!` | 안녕하세요 | 낮 인사 | 미평가 |
| `Добрый вечер!` | 안녕하세요 | 저녁 인사 | 미평가 |
| `Добро пожаловать!` | 환영합니다 | 고정 표현 | 미평가 |
| `С приездом!` | 오신 것을 환영합니다 | 도착한 사람에게 | 미평가 |
| `Спасибо!` | 감사합니다 | `Нет, спасибо.` | 미평가 |
| `Пожалуйста.` | 천만에요, 부탁합니다 | 주문·요청에도 사용 | 미평가 |
| `Очень приятно.` | 만나서 반갑습니다 | `Очень приятно познакомиться.` | 미평가 |
| `Давно не виделись!` | 오랜만입니다 | 직역: 오래 만나지 못했다 | 미평가 |
| `Сколько лет, сколько зим!` | 정말 오랜만이야 | 관용 표현 | 미평가 |
| `Кстати, ...` | 그런데, 그러고 보니 | 화제 전환 | 미평가 |
| `Ну, ...` | 자, 음, 그래서 | 대화의 흐름·감정 표시 | 미평가 |
| `Блин!` | 이런!, 젠장! | 원뜻은 블린; 약한 감탄사 | 미평가 |
| `Пора + 원형` | ~할 때다 | `Пора идти.` | 미평가 |
