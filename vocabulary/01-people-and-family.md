# 사람과 가족

| 러시아어 | 구분 | 뜻 |
|---|---|---|
| `семья` | F | 가족 |
| `мама` | F | 엄마 |
| `мать` | F | 어머니 |
| `отец` | M | 아버지 |
| `папа` | M | 아빠 |
| `бабушка` | F | 할머니 |
| `дедушка` | M | 할아버지 |
| `дядя` | M | 삼촌, 아저씨 |
| `дочь` | F | 딸 |
| `родители` | Pl. | 부모님 |
| `друг` | M | 남성 친구 |
| `девушка` | F | 젊은 여성, 여자친구 |
| `парень` | M | 젊은 남성, 남자친구 |
| `мужчина` | M | 남자 |
| `студент` | M | 남학생, 대학생 |
| `студентка` | F | 여학생, 대학생 |
| `преподаватель` | M | 교사, 강사 |
| `водитель` | M | 운전기사 |
| `герой` | M | 영웅 |
| `носитель` | M | 보유자, 매체, 운반자 |
| `носитель языка` | 표현 | 원어민 |

`девушка`는 여성 종업원을 부를 때도 쓰이지만 단어 자체가 종업원이라는 뜻은 아니다. 여성 종업원은 `официантка`다.
