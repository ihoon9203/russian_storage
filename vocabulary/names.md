# 러시아식 이름

| 정식 이름 | 애칭 | 메모·예문 | 숙련도 |
|---|---|---|---|
| `Юрий` | `Юра`, `Юрочка` | 남성 이름. `Юра, привет!` | 미평가 |
| `Даниил` | `Даня` | 러시아 전통형. `Даниил живёт в Москве.` | 미평가 |
| `Даниэль` |  | 외국 이름 Daniel을 음역한 형태 | 미평가 |
| `Кирилл` | `Кирюша`, `Киря` | 자연스럽고 널리 쓰이는 남성 이름. `Кирилл живёт в Москве.` | 미평가 |

`Юрочка`는 `Юра`보다 더 다정한 애칭이다.

`Кирилл`은 전통적인 러시아 남성 이름이며, 특별히 옛날식이거나 어색한 이름으로 느껴지지 않는다.
