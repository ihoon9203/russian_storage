# 자주 쓰는 낱말과 표현

| 러시아어 | 뜻 | 비고 | 숙련도 |
|---|---|---|---|
| `тоже` | 또한, 나도 | 부사 | 미평가 |
| `здесь` | 여기 | 부사 | 미평가 |
| `немного` | 조금 | 부사 | 미평가 |
| `осторожно` | 조심하세요, 조심스럽게 | 부사·감탄 표현 | 미평가 |
| `сколько` | 얼마나, 몇, 얼마 | 의문사 | 미평가 |
| `столько` | 그만큼, 그렇게 많이 | 지시 표현 | 미평가 |
| `какой` | 어떤, 무슨 | 형용사처럼 일치 | 미평가 |
| `как` | 어떻게, 어때 | `Как вас зовут?`, `Как твоя пицца?` | 미평가 |
| `союз` | 연합, 동맹, 접속사 | M | 미평가 |
| `любовь` | 사랑 | F | 미평가 |
| `шампунь` | 샴푸 | M | 미평가 |
| `встреча` | 만남 | F | 미평가 |
| `свидание` | 만남, 데이트 | N | 미평가 |
| `Взаимно!` | 저도요! | 상대 말에 같은 감정으로 답함 | 미평가 |
| `До встречи!` | 또 만나요! | `до + 생격` | 미평가 |
| `До свидания!` | 안녕히 가세요/계세요! | 정중한 작별 | 미평가 |
| `Извините.` | 실례합니다, 죄송합니다 | 일반적인 사과·호출 | 미평가 |
| `Простите.` | 용서해 주세요, 죄송합니다 | 조금 더 개인적·진지함 | 미평가 |
| `не надо` | 필요 없다, 하지 않아도 된다 | 상황에 따라 “하지 마” | 미평가 |
| `как будто` | 마치 ~인 것처럼 | 접속 표현 | 미평가 |
| `не сильно` | 그다지 ~하지 않게 | 부사 표현 | 미평가 |
| `выглядит классно` | 멋져 보인다 | 회화체 | 미평가 |
| `прям классно` | 정말/완전 멋지다 | 회화체 | 미평가 |
| `обращать внимание на + 대격` | ~에 주의를 기울이다 | 결합 표현 | 미평가 |
| `с видом на + 대격` | ~ 전망의 | `номер с видом на озеро` | 미평가 |
| `И я ...` | 나도 … | 앞말에 같은 내용을 덧붙임 | 미평가 |
| `А я ...` | 반면 나는 … | 대비를 나타냄 | 미평가 |
