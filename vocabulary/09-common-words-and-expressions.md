# 자주 쓰는 낱말과 표현

| 러시아어 | 뜻 | 비고 |
|---|---|---|
| `тоже` | 또한, 나도 | 부사 |
| `здесь` | 여기 | 부사 |
| `немного` | 조금 | 부사 |
| `осторожно` | 조심하세요, 조심스럽게 | 부사·감탄 표현 |
| `сколько` | 얼마나, 몇, 얼마 | 의문사 |
| `столько` | 그만큼, 그렇게 많이 | 지시 표현 |
| `какой` | 어떤, 무슨 | 형용사처럼 일치 |
| `союз` | 연합, 동맹, 접속사 | M |
| `любовь` | 사랑 | F |
| `шампунь` | 샴푸 | M |
| `встреча` | 만남 | F |
| `свидание` | 만남, 데이트 | N |
| `Взаимно!` | 저도요! | 상대 말에 같은 감정으로 답함 |
| `До встречи!` | 또 만나요! | `до + 생격` |
| `До свидания!` | 안녕히 가세요/계세요! | 정중한 작별 |
| `Извините.` | 실례합니다, 죄송합니다 | 일반적인 사과·호출 |
| `Простите.` | 용서해 주세요, 죄송합니다 | 조금 더 개인적·진지함 |
| `не надо` | 필요 없다, 하지 않아도 된다 | 상황에 따라 “하지 마” |
| `как будто` | 마치 ~인 것처럼 | 접속 표현 |
| `не сильно` | 그다지 ~하지 않게 | 부사 표현 |
| `выглядит классно` | 멋져 보인다 | 회화체 |
| `прям классно` | 정말/완전 멋지다 | 회화체 |
| `обращать внимание на + 대격` | ~에 주의를 기울이다 | 결합 표현 |
