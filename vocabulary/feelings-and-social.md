# 감정·사회관계

| 러시아어 | 구분 | 뜻 | 예문·메모 | 숙련도 |
|---|---|---|---|---|
| `любовь` | F | 사랑 |  | 미평가 |
| `встреча` | F | 만남 |  | 미평가 |
| `встречаться / встретиться` | 불완료상/완료상 재귀동사 | 만나다 | `Мы встретились около станции метро.` | 미평가 |
| `свидание` | N | 만남, 데이트 |  | 미평가 |
| `любить` | 동사 | 좋아하다, 사랑하다 | `люблю + 대격/동사원형` | 미평가 |
| `нравиться` | 동사 | 마음에 들다 | `нравится`, `нравятся` | 미평가 |
| `заботиться` | 동사 | 돌보다 | `Она заботится о семье.` | 미평가 |
| `позаботиться` | 동사 | 챙기다, 돌봄을 완수하다 | `Я позабочусь об этом.` | 미평가 |
| `скучать` | 동사 | 그리워하다 | `Я скучаю по тебе.` | 미평가 |
| `надеяться` | 동사 | 바라다, 기대하다 | `Я надеюсь на помощь.` | 미평가 |
| `познакомиться` | 동사 | 처음 만나 인사하다 | `Рад/Рада был/была познакомиться` | 미평가 |
| `пригласить` | 완료상 동사 | 초대하다 | `Я собиралась пригласить тебя поужинать.` | 미평가 |
| `собираться + 원형` | 동사 표현 | ~할 생각이다, ~하려고 하다 | 여성 과거 `собиралась`, 남성 과거 `собирался` | 미평가 |
