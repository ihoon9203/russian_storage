# 시간

| 러시아어 | 구분 | 뜻 | 예문·메모 | 숙련도 |
|---|---|---|---|---|
| `время` | N | 시간 |  | 미평가 |
| `день` | M | 날, 하루 |  | 미평가 |
| `ночь` | F | 밤 |  | 미평가 |
| `зима` | F | 겨울 | `этой зимой` — 이번 겨울에 | 미평가 |
| `лето` | N | 여름 | `этим летом` — 이번 여름에 | 미평가 |
| `раз` | M | 번, 차례 | `в следующий раз` | 미평가 |
| `сейчас` | 부사 | 지금 | `Она сейчас в Одессе.` | 미평가 |
| `сегодня` | 부사 | 오늘 | `Ты свободна сегодня?` | 미평가 |
| `вчера` | 부사 | 어제 | `Я работал вчера.` | 미평가 |
| `завтра` | 부사 | 내일 | `Я позвоню завтра.` | 미평가 |
| `в следующий раз` | 표현 | 다음번에 | `Может быть, в следующий раз.` | 미평가 |
| `в другой раз` | 표현 | 다른 때에, 다음 기회에 | `Хорошо, в другой раз.` | 미평가 |
| `Пора + 원형` | 표현 | ~할 때다 | `Пора идти.` | 미평가 |
