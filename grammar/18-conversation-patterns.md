# 18. 자주 쓰는 회화 패턴

### 자기소개

| 러시아어 | 뜻 |
|---|---|
| `Меня зовут ...` | 제 이름은 …입니다. |
| `Я из Кореи.` | 저는 한국에서 왔습니다. |
| `Я живу в Сеуле.` | 저는 서울에 삽니다. |
| `Я кореец.` / `Я кореянка.` | 저는 한국인 남성/여성입니다. |
| `Мне 33 года.` | 저는 33살입니다. |
| `Я разработчик.` | 저는 개발자입니다. |
| `Мой родной язык — корейский.` | 제 모국어는 한국어입니다. |

### 가격 묻기

- `Сколько это стоит?` — 이거 얼마예요?
- `Это сколько?` — 이거 얼마예요?/이거 얼마야? (짧은 회화체)
- `сколько` — 얼마나, 몇, 얼마
- `столько` — 그만큼, 그렇게 많이

### 작별과 반응

- `До встречи!` — 또 만나요!/다음에 봐요!
- `До свидания!` — 안녕히 가세요!/안녕히 계세요!
- `Взаимно!` — 저도요!/저도 마찬가지예요!
- 여성: `Рада была познакомиться!` — 만나서 반가웠어요!
- 남성: `Рад был познакомиться!` — 만나서 반가웠어요!

### 감정이 담긴 관용 표현

- `Ну и пожалуйста, ну и не надо.` — 그래, 마음대로 해. 그럼 됐어.
- `Ну и не очень-то и хотелось.` — 흥, 나도 그렇게까지 원했던 건 아니거든.
- `делать мозги кому-то` — 누구를 귀찮게 하다, 머리 아프게 하다. 공격적인 구어체이므로 사용에 주의한다.
