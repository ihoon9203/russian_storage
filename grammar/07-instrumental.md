# 7. 조격

`с`가 “~와 함께/~을 곁들여”라는 뜻이면 조격을 쓴다.

- `кофе с молоком` — 우유를 넣은 커피
- `блины с мёдом` — 꿀을 곁들인 블리니
- `Они говорили с Робертом.` — 그들은 로버트와 이야기했습니다.

### 시간 표현에 쓰이는 조격

시간대 명사의 조격은 문장에서 부사처럼 “~에”라는 뜻으로 자주 쓰인다.

- `утром` — 아침에
- `днём` — 낮에
- `вечером` — 저녁에
- `ночью` — 밤에

예문: `Я бегаю вечером.` — 나는 저녁에 달린다.

계절을 나타내는 명사도 조격으로 “~에”라는 시간을 표현한다.

- `этой зимой` — 이번 겨울에 (`зима → зимой`)
- `этим летом` — 이번 여름에 (`лето → летом`)
- `Вы были в России этой зимой?` — 이번 겨울에 러시아에 있었나요?
- `Я поеду этим летом.` — 저는 이번 여름에 갈 겁니다.

### `с + 조격`으로 동행·근접 표현하기

- `Мы с мамой пойдём покупать одежду.` — 엄마와 나는 옷을 사러 갈 거야.
- `поужинать со мной` — 나와 함께 저녁을 먹다
- `рядом с нами` — 우리 옆에

`мы с мамой`는 직역하면 “우리와 엄마”지만 자연스럽게는 “엄마와 나”라는 뜻이다.

### `за`, `над + 조격`

- `следить за двоюродной сестрой` — 여자 사촌을 지켜보다
- `присматривать за двоюродной сестрой` — 여자 사촌을 돌봐주다
- `Кот над коробкой.` — 고양이가 상자 위쪽에 있다.

`на + 전치격`은 표면에 닿아 있는 위치이고, `над + 조격`은 닿지 않은 채 위쪽에 있는 위치다.

### 위치를 나타내는 조격 전치사

| 패턴 | 뜻 | 예 |
|---|---|---|
| `перед + 조격` | ~앞에 | `Машина перед домом.` |
| `за + 조격` | ~뒤에 | `Парк за домом.` |
| `под + 조격` | ~아래에 | `Сумка под столом.` |
| `над + 조격` | ~위쪽에 | `Лампа над столом.` |
| `между + 조격` | ~사이에 | `Кафе между домами.` |
| `рядом с + 조격` | ~옆에 | `Магазин рядом с домом.` |

남성·중성 단수는 보통 `-ом/-ем`, 여성 단수는 `-ой/-ей`가 된다: `дом → домом`, `школа → школой`, `здание → зданием`.
