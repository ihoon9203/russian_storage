# 16. 나이와 `год/года/лет`

끝 숫자를 기준으로 고르되 11~14는 예외다.

| 숫자 | 형태 |
|---|---|
| 끝자리 1, 단 11 제외 | `год` |
| 끝자리 2~4, 단 12~14 제외 | `года` |
| 끝자리 0, 5~9 | `лет` |
| 11~14 | `лет` |

- `1 год`, `21 год`
- `22 года`, `33 года`
- `10 лет`, `11 лет`, `14 лет`, `30 лет`

따라서 `Мне 33 год`가 아니라 `Мне 33 года`가 맞다.
