# 9. 현재형 동사

현재형은 주어의 인칭과 수에 따라 변하며 성별에는 영향을 받지 않는다.

### 제1활용 예: `работать`

| 주어 | 형태 |
|---|---|
| `я` | `работаю` |
| `ты` | `работаешь` |
| `он/она` | `работает` |
| `мы` | `работаем` |
| `вы` | `работаете` |
| `они` | `работают` |

### 제2활용 예: `говорить`

| 주어 | 형태 |
|---|---|
| `я` | `говорю` |
| `ты` | `говоришь` |
| `он/она` | `говорит` |
| `мы` | `говорим` |
| `вы` | `говорите` |
| `они` | `говорят` |

3인칭 복수는 제1활용에서 `-ут/-ют`, 제2활용에서 `-ат/-ят`을 쓴다. `я`형에 단순히 `т`를 붙이는 규칙은 정확하지 않다.

- `мы живём` / `они живут`
- `мы работаем` / `они работают`
- `мы говорим` / `они говорят`

### 자주 나온 활용형

| 원형 | 배운 형태 | 뜻 |
|---|---|---|
| `жить` | `живу`, `живём`, `живут` | 살다 |
| `учиться` | `учусь` | 공부하다 |
| `говорить` | `говорю`, `говорят` | 말하다 |
| `работать` | `работаю`, `работаем`, `работают` | 일하다 |
| `хотеть` | `хочу`, `хочешь`, `хочет`, `хотите`, `хотят` | 원하다 |
| `мочь` | `могу` | 할 수 있다 |
| `знать` | `знаю`, `знаешь`, `знает`, `знаем`, `знаете`, `знают` | 알다 |
| `понимать` | `понимаю` | 이해하다 |
