# 19. 반복해서 교정한 문장

| 잘못되거나 어색한 형태 | 올바른 형태 | 이유 |
|---|---|---|
| `мы приехалт кареи` | `Мы приехали из Кореи.` | 복수 과거형과 `из + 생격` |
| `Мне 33 год.` | `Мне 33 года.` | 33에는 `года` |
| `Я говорю по русский.` | `Я говорю по-русски.` | 언어 방식은 `по-...ски` |
| `Я могу говорить кореянка.` | `Я могу говорить по-корейски.` | `кореянка`는 한국인 여성 |
| `Тебе нужен машина?` | `Тебе нужна машина?` | `машина`와 여성형 일치 |
| `Я люблю читать Толстой.` | `Я люблю читать Толстого.` | 남성 생물 대격 |
| `У меня есть машини.` | `У меня есть машина.` | 소유물은 주격 |
| `Где есть твоё сало?` | `Где твоё сало?` | 특정 물건의 위치에는 보통 `есть` 생략 |
| `мы работают` | `Мы работаем.` | `мы`의 1인칭 복수 활용 |
| `из Китайа` | `из Китая` | `-й → -я` 생격 변화 |
| `из Ираня` | `из Ирана` | 자음으로 끝난 남성 생격은 보통 `-а` |
