# 21. 동사·표현별 요구 격

단어 뜻과 함께 `동사/표현 + 전치사 + 격`을 한 덩어리로 외운다.

| 구조 | 뜻 | 예문 |
|---|---|---|
| `заботиться/позаботиться о + 전치격` | ~을 돌보다 | `Я заботилась о своей дочери.` |
| `думать/говорить о + 전치격` | ~에 관해 생각하다/말하다 | `Он говорит о работе.` |
| `обращать внимание на + 대격` | ~에 주의를 기울이다 | `Обратите внимание на дорогу.` |
| `надеяться на + 대격` | ~을 기대하다 | `Я надеюсь на вашу помощь.` |
| `видеть + 대격` | ~을 보다 | `Я вижу друга.` |
| `любить + 대격` | ~을 좋아하다, 사랑하다 | `Я люблю друга.` |
| `звонить / позвонить + 여격` | ~에게 전화하다 | `Я звоню другу.` / `Я позвоню тебе завтра.` |
| `помогать / помочь + 여격` | ~을 돕다 | `Я помогу вам.` |
| `помочь + 여격 + 원형` | ~가 …하도록 돕다 | `Я хочу помочь моему другу найти билет.` |
| `ждать + 대격/생격` | ~을 기다리다 | `Я жду друга.` / `Я жду автобуса.` |
| `скучать по + 여격` | ~을 그리워하다 | `Я скучаю по тебе.` |
| `показать + 여격 + 대격` | ~에게 ~을 보여주다 | `Покажите мне ваш телефон.` |
| `следить за + 조격` | ~을 지켜보다, 주시하다 | `Я слежу за двоюродной сестрой.` |
| `присматривать за + 조격` | ~을 돌봐주다, 봐주다 | `Я присматриваю за двоюродной сестрой.` |
| `старше/моложе + 생격 + на` | ~보다 …만큼 나이가 많다/어리다 | `Жена моложе мужа на три года.` |
| `нет + 생격` | ~이 없다 | `У меня нет машины.` |
| `состоять из + 생격` | ~로 구성되다 | `Семья состоит из трёх человек.` |
| `похож/похожа на + 대격` | ~을 닮다 | `Дочь похожа на маму.` |
| `выйти замуж за + 대격` | 여자가 ~와 결혼하다 | `Вера вышла замуж за Юрия.` |
| `жениться на + 전치격` | 남자가 ~와 결혼하다 | `Сергей женился на Ольге.` |
| `подниматься по + 여격` | ~을 따라 올라가다 | `Он поднимается по лестнице.` |

`соседка по комнате`의 `по + 여격`은 “같은 방을 기준으로 맺어진 관계”를 나타낸다. 초급에서는 표현 전체를 “여자 룸메이트”라는 덩어리로 익힌다.

한국어 번역의 조사만 따라가지 말고 러시아어 동사가 요구하는 격까지 함께 외운다. 같은 `друг`도 `видеть/любить/ждать друга`에서는 대격, `помогать/звонить другу`에서는 여격이 된다. 남성 생물명사의 대격은 생격과 형태가 같으므로 `друга`는 문장에서 대격일 수도 있다.

`ждать`는 대격과 생격을 모두 쓸 수 있다. 구체적으로 정해진 대상을 기다릴 때는 대격이 흔하고, 불특정하거나 아직 나타나지 않은 대상을 기대하는 뉘앙스에서는 생격도 자주 쓴다: `Я жду автобус.` / `Я жду автобуса.`
