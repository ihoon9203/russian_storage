# 21. 동사·표현별 요구 격

단어 뜻과 함께 `동사/표현 + 전치사 + 격`을 한 덩어리로 외운다.

| 구조 | 뜻 | 예문 |
|---|---|---|
| `заботиться/позаботиться о + 전치격` | ~을 돌보다 | `Я заботилась о своей дочери.` |
| `думать/говорить о + 전치격` | ~에 관해 생각하다/말하다 | `Он говорит о работе.` |
| `обращать внимание на + 대격` | ~에 주의를 기울이다 | `Обратите внимание на дорогу.` |
| `надеяться на + 대격` | ~을 기대하다 | `Я надеюсь на вашу помощь.` |
| `позвонить + 여격` | ~에게 전화하다 | `Я позвоню тебе завтра.` |
| `помочь + 여격` | ~을 돕다 | `Я помогу вам.` |
| `скучать по + 여격` | ~을 그리워하다 | `Я скучаю по тебе.` |
| `показать + 여격 + 대격` | ~에게 ~을 보여주다 | `Покажите мне ваш телефон.` |
| `следить за + 조격` | ~을 지켜보다, 주시하다 | `Я слежу за двоюродной сестрой.` |
| `присматривать за + 조격` | ~을 돌봐주다, 봐주다 | `Я присматриваю за двоюродной сестрой.` |
| `старше + 생격 + на` | ~보다 …만큼 나이가 많다 | `Он старше меня на год.` |
| `нет + 생격` | ~이 없다 | `У меня нет машины.` |

`соседка по комнате`의 `по + 여격`은 “같은 방을 기준으로 맺어진 관계”를 나타낸다. 초급에서는 표현 전체를 “여자 룸메이트”라는 덩어리로 익힌다.
