# 11. 동사상과 미래

| 불완료상 | 완료상 | 차이 |
|---|---|---|
| `покупать` | `купить` | 과정·반복 / 한 번 사서 완료 |
| `говорить` | `сказать` | 말하는 활동 / 한 번 전달하여 완료 |
| `говорить` | `поговорить` | 말하는 활동 / 잠깐 이야기를 나눔 |
| `ездить` | `поехать` | 교통수단으로 다니다 / 교통수단으로 출발하다 |
| `идти` | `пойти` | 걸어가는 중 / 걸어서 출발하다 |
| `заказывать` | `заказать` | 주문 과정·반복 / 한 번 주문하여 완료 |
| `разбивать` | `разбить` | 깨뜨리는 과정·반복 / 깨뜨려 결과가 생김 |
| `выбрасывать` | `выбросить` | 버리는 과정·반복 / 한 번 버려 완료 |
| `выносить` | `вынести` | 밖으로 나르는 과정·반복 / 밖으로 옮겨 완료 |
| `садиться` | `сесть` | 앉는 과정·반복 / 자리에 앉음 |
| `ломаться` | `сломаться` | 고장 나는 과정·반복 / 고장이 남 |

- `Он часто разбивает чашки.` / `Он разбил чашку.` — 그는 컵을 자주 깨뜨린다. / 그는 컵을 깨뜨렸다.
- `Я выбрасываю ненужные вещи.` / `Я выбросил ненужную вещь.` — 나는 필요 없는 물건들을 버린다. / 나는 필요 없는 물건 하나를 버렸다.
- `Он выносит стул из комнаты.` / `Он вынес стул из комнаты.` — 그는 방에서 의자를 가지고 나간다. / 그는 의자를 가지고 나갔다.
- `Друг садится на диван.` / `Друг сел на диван.` — 친구가 소파에 앉는다. / 친구가 소파에 앉았다.
- `Телевизор часто ломается.` / `Телевизор сломался.` — 텔레비전이 자주 고장 난다. / 텔레비전이 고장 났다.

- 불완료상 미래: `Я буду работать.` — 저는 일할 것입니다.
- 완료상 미래: `Я куплю книгу.` — 저는 책을 사겠습니다.
- `Что будете заказывать?` — 무엇을 주문하시겠어요?

`быть`의 미래형:

| `я` | `ты` | `он/она` | `мы` | `вы` | `они` |
|---|---|---|---|---|---|
| `буду` | `будешь` | `будет` | `будем` | `будете` | `будут` |

완료상 동사는 현재형처럼 활용해도 미래 의미를 나타낼 수 있다.

- `Я обязательно поеду этим летом.` — 나는 이번 여름에 꼭 갈 것이다.
- `Мы пойдём покупать одежду.` — 우리는 옷을 사러 갈 것이다.

`поеду`, `пойдём`은 형태상 현재형처럼 활용되지만 완료상 동사라 미래를 나타낸다.

`по-`의 기능은 동사마다 다르다. `говорить → поговорить`에서는 “잠깐 이야기하다”, `идти → пойти`에서는 “가기 시작하다”라는 완료 의미를 더한다.

- `Мы немного поговорили.` — 우리는 조금 이야기를 나눴다.
- `Мы пошли домой.` — 우리는 집으로 갔다.

식당에서 `Я буду борщ.`는 “저는 보르시로 할게요”라는 주문 상황의 구어체 생략이다. 더 분명한 요청은 `Мне борщ, пожалуйста.`이고, 일반적인 미래는 `буду + 동사원형`으로 만든다.

- `Я буду есть борщ.` — 나는 보르시를 먹을 것이다.
- `Я закажу борщ.` — 나는 보르시를 주문할 것이다.
- `Я заказал борщ.` — 나는 보르시를 주문했다. (남성 과거)
