# 8. 전치격과 위치

`в/на + 전치격`은 정적인 위치를 나타낸다.

| 기본형 | 전치격 | 예 |
|---|---|---|
| `офис` | `офисе` | `в офисе` |
| `Ливерпуль` | `Ливерпуле` | `в Ливерпуле` |
| `музей` | `музее` | `в музее` |
| `работа` | `работе` | `на работе` |
| `площадь` | `площади` | `на площади` |
| `Россия` | `России` | `в России` |
| `окно` | `окне` | `на окне` |
| `море` | `море` | `на море` |
| `здание` | `здании` | `в здании` |

`На работе`는 “일하는 중”보다 “직장에 있다”에 가깝다. 동작을 분명히 말하려면 `Я работаю.`라고 한다.

### `где`, `куда`, `откуда`

| 질문 | 뜻 | 전치사와 격 |
|---|---|---|
| `где?` | 어디에? | `в/на + 전치격` |
| `куда?` | 어디로? | `в/на + 대격` |
| `откуда?` | 어디에서부터? | `из/с/от + 생격` |

- `Я в офисе.` — 저는 사무실에 있습니다.
- `Я иду в офис.` — 저는 사무실로 갑니다.
- `Я из офиса.` — 저는 사무실에서 왔습니다.

`в`와 `на`는 명사마다 관습적으로 정해진 경우가 많다.

- `в России`, `в офисе`, `в комнате`
- `на работе`, `на площади`, `на море`, `на улице`

단순히 “방에/집에”라고 할 때는 `в комнате`, `в доме`가 자연스럽다. 내부를 강조할 때 `внутри комнаты`, 외부를 강조할 때 `снаружи дома`를 쓴다.

### `на`도 위치와 방향을 구분한다

- 위치 `на + 전치격`: `на работе`, `на улице`, `на площади`
- 방향 `на + 대격`: `на работу`, `на тренировку`, `на пробежку`

예문:

- `Я на работе.` — 나는 직장에 있다.
- `Я иду на работу.` — 나는 직장으로 간다.
- `Я иду на пробежку.` — 나는 조깅하러 간다.

### `в чём?`으로 옷차림 묻기

`В чём ты идёшь на пробежку?`는 “무엇을 입고 조깅하러 가?”라는 뜻이다. 입고 있는 옷은 `в + 전치격`으로 말한다.

- `в футболке` — 티셔츠를 입고
- `в штанах` — 바지를 입고
- `в кроссовках` — 운동화를 신고

예문: `Я иду на пробежку в футболке, штанах и кроссовках.`
