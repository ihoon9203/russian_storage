# 26. 명사 복수 격 어미표

| 격 | 일반적인 복수 어미 | 예 |
|---|---|---|
| 주격 | `-ы/-и`, 일부 `-а/-я` | `столы`, `словари`, `окна` |
| 생격 | 무어미, `-ов/-ев/-ей` 등 | `нет столов`, `пять дней` |
| 여격 | `-ам/-ям` | `к студентам`, `к словарям` |
| 대격 | 무생물=주격, 생물=생격 | `вижу столы`, `вижу студентов` |
| 조격 | `-ами/-ями` | `со студентами`, `со словарями` |
| 전치격 | `-ах/-ях` | `о столах`, `о словарях` |

복수 생격은 변화 유형과 예외가 많으므로 단어와 함께 외운다. `день → дни → дней`, `человек → люди → людей`처럼 불규칙한 형태도 있다.
